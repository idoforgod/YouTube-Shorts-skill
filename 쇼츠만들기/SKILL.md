# 쇼츠만들기

글·보고서·주제를 받아 **세로 1분 쇼츠(1080×1920)** 한 편을 만든다. 내용은 매번 다르고, 이 스킬은 **만드는 방식**만 고정한다.
대본 쓰기는 Claude가, 녹음·영상·검사는 `도구/`의 프로그램이 한다.

자리(아래 «도구/»는 이 스킬 폴더 기준): 영상 틀 `영상틀/`(Remotion 프로젝트) · 무료 음성 `수퍼토닉/` — 둘 다 이 스킬 폴더의 한 칸 위(압축 푼 폴더)에 있다. 다른 곳에 두었다면 환경변수 `SHORTS_HOME`에 그 폴더를 적는다.
도구는 아래 `<스킬>`을 이 스킬 폴더의 실제 경로(보통 `~/.claude/skills/쇼츠만들기`)로 바꿔 부른다.

## 지킬 것 (금지선)
- **남의 보도·회사 사진·영상·대본을 쓰지 않는다.** 사진은 내가 직접 찍은 것, 또는 `사진찾기.py`(퍼블릭 도메인·CC0·CC BY만)로 받은 것. CC BY는 `꼬리`와 설명란에 출처를 적는다(`출처.txt`에 저절로 기록됨).
- **숫자·사실은 받은 자료에 있는 것만.** 없는 숫자를 만들지 않는다. 확률·범위를 단정하지 않는다(자료에 없으면 «자료에 없음»).
- **올리기·게시는 하지 않는다.** 만든 파일을 사람이 확인한 뒤 직접 올린다.
- **«AI 음성» 표기.** 수퍼토닉 모델 라이선스(OpenRAIL-M)가 기계 생성 음성임을 밝히라고 한다 → 설명란에 «AI 음성». 남의 목소리를 동의 없이 흉내 내는 데 쓰지 않는다.
- **컷의 `때`는 한 낱말만.** 대본 속 낱말 하나(예: `"때": "수출기업이"`) 또는 초(숫자). 구절·문장을 적으면 시각을 못 찾는다.
- **말 = 그림 1:1.** 말하는 대상이 화면에 나온다(«연준» → 연준 사진, «7%» → 큰 숫자).

## 순서 (한 편)
1. **대본 짓기** — 받은 내용으로 «장면 JSON»을 쓴다(꼴은 아래 · 예: `본보기/`).
   - **말투 = 존댓말**(«~입니다·~습니다·~세요») · 반말 금지.
   - 뼈대: ① 첫 3초 = 보는 사람의 아픔·궁금증 + «진짜 까닭» 예고 → ② 전개(숫자 2~3개) → ③ 반전(«그런데») → ④ 끝 = 행동 부탁 한마디 + 끝나지 않은 떡밥 한 줄(`빨강` 낱말부터 빨간 자막).
   - 길이 45~55초(수퍼토닉 M1 빠르기 1.3 기준 약 400~470자) · 장면 5~8개.
   - `제목` 2줄 = 영상 내내 고정 · 각 줄 12자 안팎 · 1줄(흰) 결과 · 2줄(노랑) 반전/까닭.
   - 컷은 한 장면 안에서 **3~4초마다** 바꾼다(`때` = 그 낱말을 말할 때, 또는 초). 첫 장면 첫 컷은 **사진**(끝에서 첫 화면으로 되감기는 고리용).
2. **사진 받기** — `python3 <스킬>/도구/사진찾기.py <JSON이름> <저장이름> "<영어 검색어>"` → 컷의 `"사진": "<JSON이름>/<저장이름>.jpg"`. 내 사진을 쓰려면 `영상틀/public/사진/<JSON이름>/`에 직접 넣는다.
3. **배경음악(기본으로 깔림)** — JSON에 `음악`을 안 적으면 `차분한.mp3`가 크기 0.187로 저절로 깔리고 `꼬리`에 곡 출처가 붙는다. 다른 곡: `python3 <스킬>/도구/음악찾기.py <저장이름> "<영어 검색어>"`(퍼블릭 도메인·CC0·CC BY만) 후 JSON 맨 위 `"음악": {"파일": "<저장이름>.mp3", "크기": 0.1}`(목소리보다 작게 0.1~0.15). 처음 1초 커지고 끝 1.5초 줄어든다. 이미 들어 있는 곡: `차분한.mp3`·`밝은.mp3`(둘 다 CC BY 4.0 · 출처 `영상틀/public/음악/출처.txt`).
4. **읽기 꼴 바꾸기·검수(음성짓기.py가 자동)** — 음성 모델은 숫자·금액·날짜·영어 약자를 자주 틀리게 읽는다. 녹음 직전 `읽기바꿈.py`가 «700→칠백 · 7%→칠퍼센트 · 1723년→천칠백이십삼년 · 영어 약자→한글 소리»로 바꿔 모델에 보낸다(띄어쓰기 그대로 → **자막은 숫자, 소리는 한글 읽기**). 바꾸고도 숫자·영어·한자가 남은 낱말이 있으면 «장면 번호 + 낱말»을 찍고 **녹음하지 않고 멈춘다**(끝코드 3). 풀이: `도구/읽기사전.json`에 «원래 글: 한글 소리»를 더하거나 대본을 고쳐 다시 실행.
5. **목소리** — 기본 = 수퍼토닉 M1(남자) 빠르기 1.3(무료·CPU만으로 돎). JSON 맨 위 `"목소리": {"엔진": "수퍼토닉", "이름": "M1", "빠르기": 1.3}`. 이름은 여성 F1~F5 · 남성 M1~M5. 유료 일레븐랩스를 쓰려면 `"엔진": "일레븐랩스", "이름": "<목소리 ID>"` + 환경변수 `ELEVENLABS_API_KEY`. 수퍼토닉은 낱말 시각을 안 주므로 말한 구간을 낱말 글자 수 비율로 나눈다(자막이 소리와 조금 어긋날 수 있음). 같은 말·같은 목소리는 다시 녹음하지 않는다(엔진·목소리·빠르기를 바꾸면 다시 녹음).
6. **뽑기** — `bash <스킬>/도구/뽑기.sh <장면.json>`: 장면마다 녹음 → 영상(1080×1920 · 초당 8메가) → 시각 게이트 → 보기용 사본(30MB 아래). 결과는 `영상틀/out/<이름>.mp4`, `<이름>_보기용.mp4`.
7. **시각 게이트 통과 확인** — 불통이면 내보내지 않는다. 걸린 항목을 고쳐(대본·컷 때·틀) 다시 6번. 통과해도 `영상틀/out/게이트_<이름>.png`(1초 간격 이어붙인 판)를 **눈으로 본다**: 글자 잘림·겹침·빈 화면·깨진 장면. (예전에 기계는 통과했는데 눈으로 «700~1000m»가 잘리고 카드 목록이 자막과 겹친 것을 잡았다. 큰 글자·막대 이름·숫자는 폭에 맞춰 한 줄, 카드 목록은 한 줄 13자 안팎.)
8. **넘김** — 보기용 파일 + 한 줄(길이·게이트 통과·사진 출처 수) + «AI 음성» 표기 안내.

## 장면 JSON 꼴
```json
{"제목": ["1줄(흰)", "2줄(노랑)"], "음악": {"파일": "차분한.mp3", "크기": 0.187}, "꼬리": "날짜 · 출처 · 사진 위키미디어 공용 · 투자 권유 아님",
 "목소리": {"엔진": "수퍼토닉", "이름": "M1", "빠르기": 1.3},
 "장면": [{"말": "존댓말 대본", "빨강": "그런데(선택·끝 장면)", "컷": [{"때": 0, "꼴": "사진", ...}, {"때": "낱말", "꼴": "막대", ...}]}]}
```
`음악`·`목소리`는 안 적어도 기본값이 쓰인다.

| 꼴 | 칸 | 쓰임 |
|---|---|---|
| 사진 | 사진·기준(위치)·작은글·큰글·색·크기 | 실제 사진 + 큰 글자 쾅(히어로·섹션 첫 컷) |
| 막대 | 제목·항목[[이름,값,글,때]]·주인공·색 | 여럿 비교 · 주인공 숫자만 크게 |
| 전광판 | 이름·값·차·방향(오름/내림) | 지수·가격 한 개를 크게 + 선 그래프 |
| 게이지 | 제목·값·단위·채움(0~1)·소수·아래글 | 한 숫자의 크기감 |
| 범위 | 제목·아래·위·단위(기본 %)·최대(기본 100)·아래글 | 확률·범위(73~79%) |
| 갈림길 | 제목·주석·시작·위{때,큰,글[2],색}·아래{…} | 시나리오 두 갈래 |
| 카드 | 위글·큰글·도장·값·값색·목록[]·점(목록 앞 기호 · 기본 ✕)·색조(바탕색) | 주인공 소개 + 까닭 목록 |
| 아이콘 | 아이콘(이모지)·글1·글2 | 끝맺음·행동 부탁 |

색 이름: 흰·노랑·빨강·오름(빨강 계열)·내림(파랑)·초록·회색 — 한국식 오름 빨강 / 내림 파랑.

## 시각 게이트 (기계 12항목 · `도구/시각게이트.py`)
규격 1080×1920 · 길이 45~60초 · 화질 초당 6메가↑ · 소리 −18~−10 LUFS · 위 검정 띠 · 제목 1줄 흰 · 제목 2줄 노랑(모든 화면) · 아래 330px 비움(유튜브 버튼 자리) · 자막 90%↑ · 그림 띠 4.5초 넘게 안 멈춤 · 끝 줄 빨강 자막 · 끝 화면 = 첫 화면. **내보내기 전 마지막 문. 하나라도 ❌면 내보내지 않는다.**
